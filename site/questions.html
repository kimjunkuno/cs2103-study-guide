    Help & privacy

    Category and filter selections are remembered in this browser after a refresh. Clearing browser storage resets them. Practice starts a new random session after a reload.

    Each question has a fixed answer key and is marked when you choose Check answer. MCQ questions have four options and exactly one is correct. MRQ questions have three to five options and two or more are correct; select every correct option. An MRQ counts as correct only when your selection matches the key exactly, but the feedback still shows which options you missed and which you chose wrongly. Options are shuffled each time a question is shown.

    Questions are written for this guide from the course Topics pages (snapshot of 11 November 2026). Some apply a topic to the AddressBook-Level3 (AB3) code base and link to the files they rely on. The question bank is a draft that has not yet been reviewed by a person; check the linked topic if an answer looks wrong. These are study questions, not official exam questions.

    Allow random repeats lets random selection reuse seen questions; with it off, each question appears once per session. Try again shows the same question again with the options reshuffled. Changing week, topic, type, scope or Revisit only starts a fresh session and resets the score without clearing your saved questions. The score is not stored.

    A wrong answer saves the question for later. Skip saves it as skipped, unless it is already saved as incorrect. A correct answer removes it from the revisit list. Use Revisit only to practise saved questions.

    Some topics have no questions because the snapshot only links to external lessons: . Weeks 12–13 have no assigned topics.

    Saved flags stay in this browser, separate from flashcards and diagrams. Private browsing, clearing storage or changing browsers can lose them. Export a backup to keep them. Import replaces the list after validation; unknown question IDs are ignored.

    Independent study aid, not affiliated with NUS. No application analytics, accounts or API calls. GitHub Pages may log IP addresses for hosting security. Source credits and licence.
